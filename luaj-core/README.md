# luaj-core (FiguraMC fork, built from source)

Source of `com.github.FiguraMC.luaj:luaj-core:3.0.8-figura` (MIT License, see
https://github.com/FiguraMC/luaj), taken from the published sources jar.
`settings.gradle` of the main build includes this directory with `includeBuild`,
so Gradle builds it from here in place of the published jar. `luaj-jse` is still
the published jar.

Changes from the published fork are marked `[bh]` in the code.
